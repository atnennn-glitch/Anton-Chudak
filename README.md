# Копія anton-eduscale.com

Збережена публічна сторінка станом на 1 листопада 2026 року.

## Що входить

- Оригінальна HTML-структура, CSS, адаптивні стилі та вбудовані SVG.
- 36 локальних ресурсів: зображення, шрифти, JavaScript і стилі.
- Оригінальні анімації Webflow/GSAP та відкриття таблиці у lightbox.
- Початкові посилання на Telegram та Instagram.

## Запуск

Відкрийте термінал у цій папці та виконайте:

```sh
python3 -m http.server 8000 --directory dist
```

Перейдіть на http://localhost:8000/.

Для розміщення на іншому хостингу завантажте вміст `dist` у корінь сайту. Збірка й установлення пакетів не потрібні. Для перенесення на інший домен оновіть абсолютні URL зображень у метаданих og:image та twitter:image у dist/index.html.

## Примітки

Копія містить публічну частину сайту; кабінет Webflow, CMS та дані аналітики не експортуються з публічної сторінки. Meta Pixel та Microsoft Clarity вилучені, щоб відвідування копії не впливали на статистику оригіналу. Оригінальний сайт не змінювався.
